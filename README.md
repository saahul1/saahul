# Saahul Actor Portfolio — v1

Open `index.html` in a browser to preview the site.

## Publish on GitHub Pages
1. Create/open the GitHub repository.
2. Upload everything inside this folder.
3. Make sure `index.html` is in the repository root.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. Save.

## Before final launch
- Add Saahul's showreel URL in the Showreel section.
- Add the preferred professional email/phone.
- Replace any movie stills with officially supplied/licensed promotional stills if needed.
- Confirm exact character names before adding them to public credits.
